- {{ grade:staff }}: {{ amount:38000000 }} ~ {{ amount:56000000 }}

## 제3조(수당)
① 직책수당은 월 기준으로 {{ grade:team_leader }} {{ amount:300000 }}, {{ grade:division_head }} {{ amount:600000 }}입니다.
② 식대는 월 {{ amount:200000 }}을 비과세로 지급합니다.
③ 자격수당은 회사가 정한 자격증 1건당 월 {{ amount:50000 }}이며, 최대 2건까지 지급합니다.

## 제4조(성과급)
① 성과급은 연 1회 2월에 지급합니다.
② 지급률은 평가 등급에 따라 기본급의 S 15%, A 10%, B 5%, C 0%입니다.

## 제5조(인상)
