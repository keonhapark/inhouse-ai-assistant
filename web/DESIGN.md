# web 디자인 기준

> 재설계(#558) 중입니다. 색·글자·간격·부품 규칙은 [ux/design-system.md](../ux/design-system.md)가 기준이고, 이 문서의 원칙·부품 설명은 화면을 옮기며 그 명세로 바꿉니다.

사내 업무 도구입니다. 화려함보다 오래 봐도 피곤하지 않고, 위험한 실행과 되돌리기가 눈에 잘 띄는 것을 우선합니다.

## 원칙

- 차분한 무채색 바탕에 강조색 하나. 색은 상태(위험, 성공, 대기)를 알릴 때만 씁니다.
- 실행 전 미리보기 카드는 "무엇이 바뀌는지"를 먼저 보여 줍니다. 버튼 문구는 동사로 씁니다(실행, 취소, 되돌리기).
- 로컬 모델로 처리한 답, 근거 조문, 대결로 들어온 결재는 작은 배지로 출처를 밝힙니다.
- 키보드만으로 모든 동작을 할 수 있고, 대비는 WCAG AA(본문 4.5:1)를 지킵니다.

## 토큰

토큰의 기준은 [ux/design-system.md](../ux/design-system.md)(#563)와 [ux/design-system/tokens.css](../ux/design-system/tokens.css)입니다. `src/styles/tokens.css`는 그 파일을 그대로 옮기고, 화면을 새 이름으로 옮기는 동안(#557)만 옛 이름(`--sp-*`, `--fs-12`, `--text-muted`, `--border` 등)을 별칭으로 둡니다. 대비 시험은 `src/styles/contrast.test.ts`입니다.

## 기본 부품

| 부품 | 내용 |
|---|---|
| 버튼 | 주(accent 채움), 보조(테두리), 위험(danger 채움). 높이 32px, 비활성은 투명도 50% |
| 배지 | 위험 등급(read 회색, reversible_write warning, irreversible danger), 상태(진행·승인·반려·회수), 로컬 처리 |
| 미리보기 카드 | 머리: 에이전트 이름·도구 이름·위험 배지 / 몸: `summary`와 바뀌는 값(전 → 후) / 발: 실행·취소 버튼, 만료 시각 |
| 행동 카드 | 실행된 결과 요약과 되돌리기 버튼(`undoable`일 때만). 되돌린 뒤에는 회색으로 바뀜 |
| 근거 | 답 아래 접이식 목록. 문서 제목·조문·인용문, 인용 확인 안 된 것은 표시 |
| 결재함 표 | 양식, 제목, 요청자, 금액, 상신 시각, 상태. 대결로 들어온 행은 "대결: <원 결재자>" 배지 |
| 빈 상태·오류 | 한 문장과 다음 행동 하나. 서버 오류는 problem+json의 `title`을 그대로 보여 줌 |

## 화면(1단계)

- 직원 채팅: 왼쪽 대화 목록, 위쪽 부서 에이전트 선택(자동 선택 기본), 가운데 대화. 스트림 이벤트(`ChatEvent`)마다 위 부품을 씁니다.
- 팀장 승인함: 탭(내 차례, 대결, 처리함, 올린 것), 행을 열면 결재선과 승인·반려. 대결 설정은 같은 화면의 패널에서 미리보기 → 등록·해지.
