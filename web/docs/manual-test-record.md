# 실사용 시험 기록 양식

[실사용 시험 절차](manual-test.md)로 해 본 결과를 적는 양식입니다. 이 파일을 복사해 `eval/reports/manual/<날짜>-<팩>-<모델 조건>.md`(예: `2026-11-30-manufacturing-L.md`)로 저장하고 채웁니다. 마스킹 기준은 절차 문서 7절입니다.

## 시험 조건

| 항목 | 값 |
|---|---|
| 날짜·시간대 | 2026-MM-DD HH:MM ~ HH:MM |
| 시험한 사람 | (역할만. 예: 개발자, 지인 1) |
| 저장소 커밋 | `git rev-parse --short HEAD` |
| 팩·단계 | manufacturing / `PACK_STAGE=3` |
| 모델 조건 | L(로컬만) 또는 E(외부 허용) |
| 로컬 모델 기기 | desktop(이 PC) 또는 colab(T4, 터널 경유) |
| 브라우저·화면 | 예: Chrome 1280x800, 밝음 |

## 일별 결과

결과는 성공(기대대로) / 부분(기대와 일부 다름) / 실패(기대와 다르거나 오류) 중 하나입니다. 걸린 시간은 보내기부터 답·카드가 다 나올 때까지 초입니다.

| 번호 | 결과 | 걸린 시간(초) | 실행된 도구 | 감사 기록 | 외부 전송 | 불편했던 점 | 기대와 다른 동작 |
|---|---|---|---|---|---|---|---|
| M-AS-1 | | | | 있음 / 없음 | 없음 / 있음(가림 확인) | | |
| M-AS-2 | | | | | | | |

(절차 문서의 번호대로 줄을 더합니다. 하지 않은 일은 "안 함"과 이유를 적습니다.)

## 화면에서 걸린 것

일과 관계없이 화면을 쓰며 걸린 것을 적습니다(헷갈린 말, 찾기 어려운 버튼, 너무 긴 대기, 읽기 어려운 카드 등).

| 화면 | 무엇이 | 얼마나(사용을 막음 / 헷갈림 / 다듬기) | 스크린샷 |
|---|---|---|---|
| | | | |

## 요약

- 성공 n / 부분 n / 실패 n (전체 n)
- 걸린 시간: 중앙값 n초, 가장 긴 일 n초(번호)
- 외부 전송: 있어야 할 곳에만 있었는지, 가림이 맞았는지
- 가장 먼저 고칠 것 세 가지와 연결한 이슈 번호
