# 실사용 시험 절차

자동 평가(eval)가 끝난 뒤 사람이 웹 화면으로 직접 써 보는 시험입니다. 자동 평가가 잡지 못하는 것, 즉 화면에서 헷갈리는 곳, 답을 기다리는 시간, 기대와 다른 동작을 찾는 것이 목적입니다. 시험 문장은 이 문서를 위해 새로 쓴 것이고 평가 셋(확인 셋)과 겹치지 않습니다. 결과는 [기록 양식](manual-test-record.md)에 적습니다.

## 1. 스택 띄우기

제조 팩을 3단계(연구소·품질·영업 에이전트까지)로 띄웁니다. `PACK_STAGE`를 주지 않으면 팩 기본 단계(제조 2단계)라 3단계 에이전트가 목록에 없습니다.

```bash
cp .env.example .env              # 처음 한 번. ERP_DEMO_PASSWORD, LITELLM_MASTER_KEY 등을 채웁니다
bash scripts/dev-keys.sh          # 위임 토큰 개발 키(처음 한 번)
source scripts/env.sh 6           # 포트(세션 번호별). 웹은 http://127.0.0.1:$PORT_WEB
export PACK_STAGE=3
docker compose -f infra/compose.yaml --env-file .env --profile full up -d --build --wait
```

로컬 모델을 쓰는 동안은 GPU 사용권을 받습니다(`docs/workflow.md` 5절).

```bash
bash scripts/gpu-lease.sh take desktop web 90 "실사용 시험"
# … 시험 …
bash scripts/gpu-lease.sh release desktop
```

모델 조건은 두 가지로 나눠 따로 기록합니다.

| 조건 | 설정 | 기대 |
|---|---|---|
| L(로컬만) | `.env`의 `ANTHROPIC_API_KEY`를 비웁니다 | 모든 답이 "로컬에서 처리". 외부 전송 기록이 비어 있음 |
| E(외부 허용) | `ANTHROPIC_API_KEY`를 넣습니다 | `external_allowed` 에이전트(전사 비서·구매자재·품질·영업)는 외부 모델을 쓸 수 있고, `local_only` 에이전트(인사·재무·IT운영·연구소)와 사진을 읽는 턴은 로컬에 남음 |

L 조건에서 외부를 쓰는 에이전트가 어떻게 답하는지(로컬 폴백, 오류 안내)도 그대로 적습니다. 끝나면 `docker compose -f infra/compose.yaml --profile full down`으로 내립니다.

## 2. 계정

모든 직원의 비밀번호는 `.env`의 `ERP_DEMO_PASSWORD`입니다. 직원과 회사는 지어낸 것입니다.

| 쓰임 | 사번 | 소속·직급 | 역할 |
|---|---|---|---|
| 일반 직원(타 부서) | E0034 | 생산관리팀 팀원 | 직원 |
| 일반 직원의 팀장(휴가·경비·구매 1단계 결재자) | E0030 | 생산관리팀 팀장 | 직원 |
| 본부장(100만 원 넘는 경비 2단계 결재자) | E0004 | 생산본부 본부장 | 직원 |
| 대결 받을 사람 | E0036 | 생산관리팀 팀원 | 직원 |
| 재무 담당 | E0013 | 재무팀 팀원 | 재무 담당 |
| 구매 | E0046 | 구매자재팀 팀원 | 직원 |
| 품질 | E0040 | 품질팀 팀원 | 품질 확인 |
| 연구소 | E0053 | 연구개발팀 팀원 | 직원(연구 기밀 문서 접근) |

## 3. 일마다 확인할 것

| 무엇 | 어디서 보는지 |
|---|---|
| 답 | 채팅의 답 글과 카드. 맞는 내용인지, 근거(규정 인용)가 붙었는지, 되물음이 필요한 만큼만인지 |
| 실행된 도구 | 답 위의 "도구 실행" 줄, 실행한 일 카드, 실행 미리보기 카드(실행·취소), 결과로 바뀐 데이터(승인함, 다시 물어보기) |
| 감사 기록 | E0057로 로그인 → 관리 → 감사 로그. 시험한 시각·직원·에이전트의 줄이 있는지, 거절된 요청도 남았는지 |
| 외부로 나간 여부 | 답 아래 "로컬에서 처리" 배지(없으면 외부 모델). 관리 → 외부 전송 기록에서 그 요청이 있는지, 이름·사번·연락처가 가려졌는지 |

걸린 시간은 보내기를 누른 때부터 답이나 카드가 다 나온 때까지 초 단위로 적습니다.

## 5. 금융 팩(짧게)

compose는 제조 팩으로 고정돼 있어, 다른 팩은 덮어쓰기 파일로 `PACK_DIR`을 바꿔 띄웁니다. 파일은 저장소 밖에 둡니다. 금융 팩은 팩 단위로 외부 LLM을 막아(`model_policy_override: local_only`) L 조건만 봅니다.

```yaml
# 예: ~/pack-finance.yaml
services:
  erp: {environment: {PACK_DIR: /packs/finance}}
  rag: {environment: {PACK_DIR: /repo/packs/finance}}
  agent: {environment: {PACK_DIR: /repo/packs/finance}}
  gateway: {environment: {PACK_DIR: /repo/packs/finance}}
```

```bash
unset PACK_STAGE
docker compose -f infra/compose.yaml -f ~/pack-finance.yaml --env-file .env --profile full up -d --wait
```
