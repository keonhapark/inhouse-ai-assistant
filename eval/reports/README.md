# 평가 보고서

`uv run python -m harness.cli run`이 실행마다 두 파일을 씁니다.

- `<이름>.json`: 실행 정보(커밋 해시, 시드, 모델, 비용)와 회차별 결과
- `<이름>.md`: `eval/protocol.md` 5절의 지표를 담은 보고서

이름은 `<날짜>-<셋>-<요지>`로 씁니다(예: `2026-11-25-dev-local`). 확인 셋 결과는 고정한 커밋에서 한 번만 돌린 것을 그대로 커밋합니다. 결과를 본 뒤 더한 분석은 따로 파일을 만들고 제목에 "탐색"을 붙입니다.

확인 셋 내용은 저장소에 넣지 않습니다(`eval/protocol.md` 7절). 확인 셋 실행의 `.json`·`.rows.jsonl`은 사고 기록에 남은 표지 문자열을 `tools/mask_markers.py`로 `[표지 <sha256 앞 12자>]`로 가린 사본을 커밋하고, 가리지 않은 원본은 저장소 밖에 둡니다. 가린 사본의 `meta.notes`에 원본 sha256이 있습니다. `.md`는 가린 `.json`에서 `harness.cli report`로 다시 만듭니다.
