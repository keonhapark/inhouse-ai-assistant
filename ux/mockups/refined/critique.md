근거: `ux/mockups/refined/{chat,approvals}-{light,dark}.png`(1440×900), `refined.css`, `src/refined.mjs`, `ux/copy-guide.md`.
좌표는 1440×900 그림 기준 (x, y)입니다.


> 따로 띄운 `UI Designer` 에이전트가 만든 쪽의 설명 없이 그림과 코드만 보고 쓴 비평입니다(첫 판 기준). 뒤에 반영한 것:
> 1 아바타 글자·결재 건수 위치 버그, 보조 글 대비(밝음 #66666b, 어두움 #a8a8ad), 세그먼트 숫자, 날짜·요일(오늘을 11월 20일 금요일로 맞춤) / 2 선택 표시를 회색 하나로, 파란색은 동작에만 / 3 확인 카드 금액을 위로, 겹친 문장·태그 정리, 에이전트 답을 한 문장으로 / 4 결재선을 기안자 아래 가로 한 줄로, 결제 수단·참석자·계정과목 칸 / 5 꼬리 있는 왼쪽 정렬 팝오버, 하단 한 줄, 눌린 승인은 흐리게 / 6 세그먼트를 툴바로, 같은 이름 그룹 머리와 셰브런 제거, "오늘 결재 완료" / 7 상태색 채도 낮춤, 주황 태그를 중립 글자 + 아이콘으로, 어두움에서 영수증 밝기 낮춤 / 8 글자 크기 단계 정리(12·13·14·15·17·22·28px) / 5절 문구 16건 모두.

## 2. 가장 좋은 점 3개

1. **결재 화면의 골격.** 세그먼트(결재 대기 3 / 대결 대기 1 / 결재 완료 / 기안함)로 함을 나누고, 왼쪽 목록에서 고르면 오른쪽에 상세가 열리는 마스터-디테일 구조입니다. 상세에서는 금액(34px, tnum)이 제목보다 먼저 읽히고, 영수증 썸네일이 값 표 바로 옆에 있어 대조하기 쉽습니다(949~1411, 196~460). 함 이름도 copy-guide 용어와 맞습니다.
2. **실행 전 확인 카드의 흐름.** 왼쪽 영수증, 오른쪽 읽은 값, 그 아래 한도 판정과 결재선, 바닥에 "12:50까지 확인"과 `취소` / `경비 정산 상신`이 놓여 있습니다(636~1316, 225~672). 직원이 확인할 것, 일어날 일, 남은 시간이 한 카드 안에 다 있고, 버튼이 무엇을 하는지 이름에 드러납니다.
3. **토큰 바탕.** 애플 시스템 그레이 계열 면(#f5f5f7/#1c1c1e/#2c2c2e), 0.5px 구분선, 왼쪽 16px 들여 시작하는 inset grouped 구분선, 점+글자 상태 표시(색만으로 뜻을 전하지 않음), 밝음·어두움 변수가 같은 이름으로 짝지어진 구조입니다. 고칠 때 토큰 몇 개만 바꾸면 전체에 반영됩니다.

## 3. 가장 거슬리는 점 5개

1. **선택 표시가 세 가지입니다.** 사이드바는 회색 둥근 면(12~227, 123~153), 대화 목록은 꽉 찬 파란 면에 흰 글자(248~503, 60~118), 결재 목록은 옅은 파란 면에 파란 제목(268~892, 184~246)입니다. 이 때문에 채팅 화면 윗부분에 파란 덩어리가 브랜드 마크, 사이드바 아이콘 다섯 개, 선택된 대화, 내 말풍선, 상신 버튼, "크게 보기"까지 이어집니다. 강조색은 하나지만 쓰인 곳이 너무 많아서, 정작 눌러야 할 `경비 정산 상신`(1190, 644)에 시선이 모이지 않습니다.
2. **구현 버그 두 개가 바로 보입니다.**
   - 결재 상세 기안자 아바타(962, 156)가 밝음에서 빈 회색 원으로 보입니다. `.detail__who span { color: var(--text-2) }`(특이도 0,1,1)가 `.avatar { color:#fff }`(0,1,0)를 덮어써서 글자색이 면색과 같아졌습니다.
   - 사이드바 "결재 3"의 숫자가 오른쪽 끝이 아니라 항목 가운데쯤(142, 167)에 떠 있습니다. `.nav__item span { flex: 1 }`이 라벨과 `.nav__count`(이것도 span) 둘 다에 걸렸기 때문입니다.
3. **날짜·요일이 서로 어긋납니다.** 금액과 날짜가 생명인 화면이라 업무 사용자는 이런 데서 바로 신뢰를 잃습니다.
   - 같은 문서인데 목록은 "오늘 12:44"(324, 225), 결재선은 "어제 12:44"(1356, 561), 헤더는 "2026년 11월 21일 12:44 상신"으로 적혀 있습니다.
   - 사용일 "2026. 11. 21. (금)"(1158, 331)이라고 했지만 2026-11-21은 토요일입니다.
   - 직원은 "어제 팀 점심 영수증이야"라고 말했는데(1028, 98) 사용일과 상신일이 같은 날입니다.
   - "연차 11월 27일~28일, 2일"(324, 265)에는 토요일(28일)이 들어 있습니다.
4. **승인 확인 팝오버의 위치와 형태가 어색합니다**(1116~1416, 702~826).
   - 꼬리(화살표)가 없어서 팝오버인지 떠 있는 카드인지 알기 어렵습니다.
   - 의견 칸을 덮어 자리 표시 글이 "반려 사유를"에서 잘립니다(961, 817).
   - 바로 아래에 눌린 링이 둘린 `승인`(1382, 864)이 그대로 보여서 화면에 `승인` 버튼이 둘입니다.
   - 가운데 정렬 2버튼은 macOS 경고창 문법이라 팝오버 문법과 섞였습니다.
5. **확인 카드 안에서 같은 말이 겹치고 금액이 묻혀 있습니다.**
   - 에이전트 문장(636, 195)이 한도 판정과 결재선을 말하고, 카드가 한도 줄(810, 555)과 결재선 줄(656, 591)로 같은 내용을 다시 보여 줍니다.
   - 머리의 주황 태그 "사진에서 읽은 값"(1203, 251)과 부제 "사진에서 읽은 값입니다."(656, 279)도 같은 말입니다.
   - 직원이 가장 먼저 대조해야 할 금액은 다섯 줄 중 세 번째 줄(1186, 423)에 있습니다. 결재 화면에서는 금액을 맨 위로 뽑아 놓았으니 두 화면의 위계가 서로 다릅니다.
   - 주황은 태그(채팅·결재 목록), 상태점, 보라는 "사내 처리"와 대결 안내 아이콘에 쓰여서 강조색 외 색이 셋이나 돌아다닙니다.

(그 밖에: 결재 목록 아래 300px가 비어 있습니다(268~892, 600~900). "결재 대기" 탭 안에 "오늘 처리" 그룹이 섞여 "결재 완료" 탭과 역할이 겹칩니다. 선택된 세그먼트 바로 아래에 같은 이름의 그룹 머리 "결재 대기"(284, 167)가 한 번 더 나옵니다. 마스터-디테일 목록에 iOS식 셰브런 ›(866, *)이 붙어 있습니다.)

## 4. 고치면 효과가 큰 수정 (우선순위 순)

### 1) 버그·대비 일괄 수정
```css
/* 아바타 글자: 상세의 span 규칙에서 빼기 */
.detail__who > span:not(.avatar) { color: var(--text-2); }   /* 기존 .detail__who span 대체 */
/* 결재 개수 오른쪽 끝으로 */
.nav__item > span:first-of-type { flex: 1; }                  /* 기존 .nav__item span 대체 */
.nav__count { flex: none; }
/* 세그먼트 선택 칸 숫자 */
.seg button.is-on .n { color: inherit; opacity: .7; }
/* 보조 글 대비 */
:root { --text-2: #66666b; --gray: #66666b; }                 /* 사이드바 4.98, 검색칸 4.59 */
/* 어두움 두 곳(미디어 쿼리, [data-theme='dark']) */
--text-2: #a8a8ad; --gray: #a8a8ad;                           /* surface-2 5.40, fill-2 4.71 */
.conv.is-active time, .conv.is-active .conv__sub { color: #fff; }  /* 2)를 안 하면 */
```
데이터는 날짜를 한 기준으로 맞춥니다. 오늘이 11월 21일(토)이면 사용일은 `2026. 11. 20. (금)`, 결재선 기안 시각은 목록과 같은 `오늘 12:44`(또는 상세 형식 `2026년 11월 21일 12:44`)로 씁니다. 연차는 평일(예: 11월 26일~27일)로 바꿉니다.

### 2) 목록 선택 표시를 하나로, 파란색은 동작에만
```css
.conv.is-active a { background: var(--sel); color: var(--text); }
.conv.is-active time, .conv.is-active .conv__sub, .conv.is-active .status { color: var(--text-2); }
.conv.is-active .status::before { background: var(--c, var(--gray)); }   /* 흰 점 규칙 삭제 */
.doc-row.is-selected a { background: var(--sel); }
.doc-row.is-selected .doc-row__title { color: var(--text); }
```
사이드바·대화 목록·결재 목록이 같은 회색 둥근 선택을 쓰게 됩니다. 이렇게 하면 파란색은 내 말풍선, 주 버튼, 링크, 결재 대기 점에만 남습니다. 대화 목록 선택은 `.convs ul` 안쪽 8px 여백이 있어 이미 둥근 알약 모양이 나옵니다.

### 3) 확인 카드: 금액을 위로, 겹치는 말 걷어내기
- 머리 바로 아래에 `<div class="sheet__amount"><b>42,000원</b><span>1인 10,500원 · 식대 한도 안</span></div>`를 두고 `.sheet__amount b { font-size: 28px; font-weight: 700; font-feature-settings: 'tnum'; }`로 씁니다. 행 목록에서는 금액 줄을 빼서 결재 상세와 같은 위계로 맞춥니다.
- 부제 `<p>`는 지우고 태그 "사진에서 읽은 값" 하나만 남깁니다. 확인 요청 문장은 footer의 `.when` 왼쪽이나 태그 옆에 "영수증과 맞는지 확인해 주세요"로 한 번만 씁니다.
- 한도 줄(`.note--ok`)과 결재선 줄을 한 줄로 합칩니다: `결재선 서도윤 팀장 · 결재 전 회수 가능`. 한도는 금액 옆으로 옮겼으니 지웁니다.
- 에이전트 문장은 "영수증에서 가맹점, 사용일, 금액을 읽었습니다." 한 문장으로 줄입니다(copy-guide 2.4 "결과 한 문장 + 카드").

### 4) 결재 상세: 결재선을 위로, 결재에 필요한 칸 추가
- 결재선을 기안자 줄 바로 아래 가로 한 줄로 올립니다: `오지현 기안 ✓ ─ 서도윤 팀장 결재 대기`. `.timeline { flex-direction: row; gap: 24px; }`로 바꾸고 세로 연결선(`li + li::after`)은 `left:auto; top:50%; width:16px; height:1px; margin-left:-20px`로 가로선으로 바꿉니다. 한국 결재 문서는 결재란이 위에 있어서 이 자리가 익숙합니다. 빈 아래 공간(949~1411, 610~785)도 줄어듭니다.
- 행 목록에 `결제 수단  법인카드 ****-1460`, `참석자  오지현 외 3명`(누르면 펼침), `계정과목  복리후생비 · 식대`를 더합니다. 팀장이 식대 정산을 승인할 때 실제로 보는 칸입니다.
- 사용일 표기를 상세 형식에 맞춥니다: `2026년 11월 20일 (금)`.

### 5) 승인 확인: 꼬리 있는 팝오버, 의견 칸과 겹치지 않게
- 하단을 한 줄로 바꿉니다: `[의견 입력 칸 ··········] [반려] [승인]`. `.detail__foot { flex-direction: row; align-items: center; }`, `textarea { flex: 1; height: 36px; }`로 쓰면 높이가 46px 줄고, 팝오버가 의견 칸을 덮지 않습니다.
- 팝오버: `right: 24px; bottom: 64px; width: 280px; text-align: left;`. 버튼은 오른쪽 정렬(`display:flex; justify-content:flex-end`, 각 `width:auto`)로 바꾸고 꼬리를 답니다.
  ```css
  .popover::after { content:''; position:absolute; right:30px; bottom:-6px; width:12px; height:12px;
    background: inherit; transform: rotate(45deg); box-shadow: 0.5px 0.5px 0 rgb(0 0 0 / 8%); }
  ```
- 팝오버가 열린 동안 아래 `승인`은 `.is-pressed`의 링 대신 `opacity:.5`로 눌림만 보여 주고, 팝오버 안의 `승인`이 유일한 주 버튼이 되게 합니다.
- 의견을 적었다면 팝오버 본문에 한 줄 보여 줍니다(`의견: 확인했습니다`). 없으면 지금 문장 그대로 둡니다.

### 6) 결재 목록: 세그먼트는 툴바로, 목록은 촘촘하게
- `.seg`를 툴바 가운데로 옮깁니다(`.toolbar h1` 뒤, `margin: 0 auto`). 그러면 목록 위 약 50px가 확보됩니다. macOS 툴바 세그먼트와 같은 자리입니다.
- 선택 탭과 같은 이름인 그룹 머리 "결재 대기"를 지웁니다.
- "오늘 처리" 그룹은 "결재 완료" 탭으로 보냅니다. 남겨야 한다면 머리를 "오늘 결재 완료"로 하고 기본으로 접어 둡니다.
- 셰브런을 없앱니다: `.doc-row a { grid-template-columns: 28px 1fr auto; min-height: 52px; padding: 8px 16px; }`, `.chev { display:none }`. 상세가 옆에 열리는 목록이라 ›가 뜻하는 것이 없습니다.
- 오른쪽 보조값을 기다린 시간 대신 기한 기준으로 바꿉니다(아래 문구 표 참고). 결재 대기가 여러 건이 되면 기안일 순, 기한 순 정렬 메뉴를 그룹 머리 오른쪽에 둘 자리가 생깁니다.

### 7) 상태색 채도 낮추기, 주황 태그 중립화
- 어두움: `--green: #5cbf6e; --orange: #d9a45a;`로 바꿉니다(각각 #2c2c2e 위 6.06·6.24). 밝음: `--green: #2a7a3d`는 그대로 써도 되고, 한도 판정 `.note--ok b`는 `color: var(--text)`로 바꿔 초록은 아이콘에만 남깁니다.
- `.tag { color: var(--text-2); background: var(--fill-2); padding: 2px 8px; border-radius: 6px; } .tag .i { color: var(--orange); }`로 씁니다. 주의 표시는 아이콘 색만 맡고, 글자는 중립으로 둡니다.
- 대결 안내 아이콘 `.pane-note .i { color: var(--text-2); }`. 보라는 "사내 처리" 한 곳에만 씁니다.
- 어두움에서 영수증이 하얗게 튀지 않게 `.receipt { filter: brightness(.86) drop-shadow(0 1px 2px rgb(0 0 0 / 30%)); }`를 어두움 블록에 넣습니다.

### 8) 글자 크기 토큰으로 정리
지금 쓰는 크기는 11, 12, 12.5, 13, 13.5, 14, 14.5, 15, 17, 22, 26, 34px로 12단계이고, 0.5px 차이 단계는 눈으로 구분되지 않습니다. 7단계로 묶습니다.
```css
--fs-caption: 12px;  /* 11, 12, 12.5 */
--fs-footnote: 13px; /* 13, 13.5(라벨·보조) */
--fs-body: 14px;     /* 13.5(본문 행), 14, 14.5 */
--fs-headline: 15px; /* 툴바 제목, 팝오버 제목 */
--fs-title3: 17px;   /* 카드 제목 */
--fs-title2: 22px;   /* 상세 제목(26→22) */
--fs-title1: 28px;   /* 금액(34→28, 카드·상세 공통) */
```
상세 제목을 22px로 낮추면 금액(28px)과 제목이 서로 다투지 않습니다.
