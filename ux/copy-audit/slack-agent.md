- 기준: `ux/copy-guide.md`
- 범위: `channels/slack/src/`(render.ts, bridge.ts, gateway.ts, slack-app.ts), `agent/src/agent_runtime/`(router.py, run/graph.py, run/policy.py, run/runner.py, run/image_reading.py, mcp_server/tokens.py, llm.py)
- 뺀 것: 시험 파일, fixtures, `agent/eval_dev`·`lora`, `agent_runtime/evaluation/`, `agent_runtime/baseline/`(슬롯 기준선), `decision_router.py`(#303 비교용), 코드 주석, `packs/`
- 사용자에게 보이는지 확인한 경로
  - 라우터 `reason`: gateway `chat.py:300`이 route 이벤트로 넘기고 web `ChatPage.tsx:304`가 직원 화면에 그대로 보입니다.
  - 정책 `reason`·runner의 `blockedReason`: gateway `chat.py:257`이 blocked 이벤트로 넘기고 슬랙 `render.ts:86`이 `*차단* …`으로 보입니다.
  - runner의 `_blocked`·`_failed` 메시지, graph의 `final`: assistant 메시지로 직원에게 보입니다.
  - `toolLabel`: 계약(`contracts/openapi/gateway.yaml:832`)에만 있고 gateway·agent에서 채우는 곳을 찾지 못했습니다. 지금은 슬랙 카드에 코드 이름(`a.tool`)이 나올 것으로 봅니다(확인 필요).

## 5. 용어집에 없는데 정해야 할 말

1. **도구 표시 이름**(30개 도구 전부). 1.2에는 `규정 검색` 예 하나뿐입니다. `toolLabel`을 채울 출처(계약, 팩, gateway 중 어디)도 정해야 합니다.
2. **도구별 실행 버튼 이름**. 1.2 예시는 `경비 정산 상신`, `회의실 예약`, `결재 회수` 셋뿐입니다. 쓰기 도구마다 필요합니다.
3. **실행 전 확인 카드의 변경 필드 표시 이름**(`startsAt`, `roomId`, `amount` 등)과 값 형식.
4. **실행 전 확인에서 `취소`를 누른 뒤의 상태 이름**. 실행 취소 결과인 `취소됨`과 구분할 말(후보: `실행 안 함`).

6. **실행한 일 카드의 제목**. `실행한 일`을 그대로 둘지 `완료`로 바꿀지.
7. **제품 이름**. 지금 `사내 AI 비서`(프롬프트), `사내 비서`(슬랙 gateway.ts:24), 1.2 제목은 `AI 비서`입니다.
8. **직원 화면에서 "모델"을 부르는 말**. 1.2에는 `외부 AI 사용`만 있습니다(예: `AI 응답이 늦어…`).
9. **부서를 고르지 못했을 때 받는 기본 에이전트(fallback)를 직원에게 부르는 이름**.
