사내 AI 비서 웹 재설계(#558)의 디자인 시스템입니다(#563). web이 화면을 갈아 끼울 때(#557) 이 문서와 토큰 파일을 기준으로 삼습니다.

- **기준 시안:** [mockups/refined/](mockups/refined/)(AI 비서·결재, 밝음·어두움). 비교 페이지는 [mockups/index.html](mockups/index.html)입니다.
- **토큰 파일:** [design-system/tokens.css](design-system/tokens.css). web은 이 파일을 `web/src/styles/tokens.css`로 옮겨 씁니다. 대비 시험은 `ux/design-system/tokens.test.mjs`(`npm test`)입니다.
- **문구:** [copy-guide.md](copy-guide.md). 버튼·배지·안내 문장은 모두 용어집을 따릅니다.
- **구조:** [research/ia.md](research/ia.md) 2절(왼쪽 탐색 막대 업무·회사·운영, 역할별 첫 화면, 결재와 대결 설정 분리, 결재 목록-상세 나란히).

### 원칙

1. **위계는 글자로 만듭니다.** 크기·굵기·색 단계로 정보의 순서를 정하고, 테두리·배지·색 면은 줄입니다. 한 화면의 주인공(금액, 문서 제목)은 하나입니다.
2. **강조색은 동작에만.** 파우더 블루는 주 버튼, 링크, 선택에만 씁니다. 상태색(라벤더 진행·초록·주황·빨강)은 점·아이콘·짧은 글자로만 쓰고 면으로 깔지 않습니다.
3. **판단할 값을 먼저.** 금액·결재선·누가 결재하는지가 카드와 상세의 맨 위에 옵니다. 코드 값·ID·원본 JSON은 기본으로 보이지 않습니다.
4. **업무 도구의 밀도.** 행 높이 44~52px, 한 화면에 결재 대기와 오늘 결재 완료가 함께 보이는 밀도를 지킵니다. 장식 때문에 스크롤이 늘지 않게 합니다.
5. **확인은 한 번 더, 실행 취소는 쉽게.** 실행 취소할 수 없는 일은 실행 전에 확인을 한 번 받습니다. 채팅에서는 실행 전 확인 시트가 그 확인이고(결재 회수 등), 결재·대결 화면에서는 버튼에 딸린 팝오버입니다(승인, 반려, 대결 해제). 실행 취소할 수 있는 일은 바로 하고 실행 취소를 붙입니다.
6. **애플 HIG의 공개 원칙을 따르되 애플 자산은 쓰지 않습니다.** 애플 로고, SF Symbols(애플 플랫폼 밖 사용 불가), SF 서체(웹 배포 라이선스 없음), 애플 화면을 가져오지 않습니다. 서체는 Pretendard(OFL), 아이콘은 Lucide(ISC)입니다.

### 2.3 글자

서체는 Pretendard 하나입니다. 숫자 열(금액, 시각, 문서 번호)은 `font-feature-settings: var(--num)`(고정폭 숫자)으로 줄을 맞춥니다. 굵기는 `--fw-*` 넷 중 하나만 씁니다.

| 쓰임 | 크기 | 굵기 | 자간 | 줄 간격 |
|---|---|---|---|---|
| 금액(시트·상세) | `--fs-title1` 28px | bold 700 | -0.025em | title |
| 상세 문서 제목 | `--fs-title2` 22px | bold 700 | -0.02em | title |
| 시트 제목 | `--fs-title3` 17px | bold 700 | -0.015em | title |
| 툴바 제목, 대화 목록 머리, 팝오버 제목 | `--fs-headline` 15px | semibold 600 | -0.01em | title |
| 본문, 값, 에이전트 답 | `--fs-body` 14px | regular 400 | -0.005em | body |
| 목록 행 제목(대화·결재), 탐색 메뉴 선택 | `--fs-body` 14px | semibold 600 | -0.005em | body |
| 라벨, 보조 줄, 탐색 메뉴 | `--fs-footnote` 13px | regular 400 | 0 | body |
| 버튼, 세그먼트, 묶음 머리 | `--fs-footnote` 13px | semibold 600 | 0 | body |
| 시각, 칩, 태그, 상태 글자, 도움말 | `--fs-caption` 12px | regular 400(메뉴 묶음 이름만 600) | 0 | body |

- 줄 간격은 본문 `--lh-body` 1.5, 제목 `--lh-title` 1.25입니다. 한글이 단어 중간에서 끊기지 않게 `word-break: keep-all`을 씁니다.
- 대문자 눈썹 라벨, 한 단어만 색을 바꾼 제목은 쓰지 않습니다.
- 시안의 13.5·14.5px, 550·650 굵기, 답 줄 간격 1.6은 이 표의 값으로 맞춰 구현합니다(시안은 그림용).
- **날짜·시각 표기**(2026-11-24 리드 결정, 구현 #638 기준). 그룹웨어에서 흔한 꼴로 모든 화면이 같게 씁니다.

  | 쓰임 | 꼴 | 예 |
  |---|---|---|
  | 날짜 | 점 구분, 끝에 점 | `2026. 11. 24.` |
  | 날짜(요일이 필요한 곳: 고르개, 사용일) | 날짜 + 괄호 요일 | `2026. 11. 24.(화)` |
  | 시각 | 오전·오후 + 12시간제 | `오후 2:30`, `오전 11:20` |
  | 날짜와 시각 | 날짜 + 시각 | `2026. 11. 22. 오전 11:20` |
  | 목록의 언제 | 오늘·어제는 말로, 그 전은 날짜 | `오늘 오전 11:20`, `어제 오후 4:53`, `2026. 11. 20.` |
  | 기간 | 물결표, 앞뒤 띄움 | `2026. 11. 23. ~ 2026. 11. 25.` |
  | 시 고르개 | 오전·오후 + 시 | `오전 9시`, `오후 6시` |
  | 화면 낭독기 이름 | 한글 날짜 + 요일 이름 | `2026년 11월 24일 화요일` |

  처음 명세는 24시간제(`14:30`)와 `2026년 11월 24일`이었으나, 구현이 위 꼴로 모든 화면에 적용된 뒤 리드가 구현을 기준으로 정했습니다(#564 비교 R-1).

## 3. 컴포넌트 규칙

### 3.1 앱 셸

- **왼쪽 탐색 막대:** 반투명 바탕(`--sidebar-bg` + 흐림), 위에서부터 브랜드(회사 이름) → 찾기·이동(Ctrl K) → 메뉴 묶음(업무·회사·운영) → 아래 끝 사용자. 메뉴 항목은 아이콘(17px, `--accent`) + 이름, 선택은 `--sel` 둥근 면(`--r-xs`). 결재 메뉴 오른쪽 끝에 결재 대기 건수(`--text-2`, tnum). 운영 묶음은 감사 권한이 있을 때만 보입니다.
- **툴바:** 높이 52px, `--surface`, 아래 0.5px 구분선. 왼쪽 화면 제목(`--fs-headline`) + 보조 글, 가운데 화면별 세그먼트 컨트롤(결재), 오른쪽 알림. 알림은 새 알림이 있으면 빨간 점.
- **명령 팔레트(Ctrl K):** 화면 가운데 위쪽에 뜨는 시트(`--r-lg`, `--shadow-pop`). 동작: 새 대화, 결재 대기 열기, 결재 문서 찾기, 대결 지정, 사람 찾기, 화면 이동, 테마 바꾸기(ia.md 2절). 키보드로 위아래 고르고 Enter, Esc로 닫음.
- **테마:** 사용자 메뉴(탐색 막대 아래 사용자 이름)에 밝음·어두움·시스템. `data-theme`로 덮어씁니다.

### 3.2 버튼

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 주 버튼 | `--accent-fill` 면, `--on-accent` 글자, `--r-sm`, `--control-h` | 화면·카드당 하나: 경비 정산 상신, 승인 |
| 보조 버튼 | `--fill` 면, `--text` 글자 | 취소, 다시 시도 |
| 위험 버튼 | `--fill` 면, `--danger` 글자 | 반려, 대결 해제, 결재 회수 |
| 링크 버튼 | 면 없음, `--accent` 글자 | 크게 보기, 결재 문서 보기 |
| 아이콘 버튼 | 30×30, 면 없음, `--text-2` 아이콘(`--icon-lg`), `aria-label` 필수 | 새 대화, 알림 |

- 버튼 글자는 `--fs-footnote` semibold. 문구는 동사 명사형 2~6자(copy-guide 2.2).
- 같은 줄에 주 버튼은 하나만, 오른쪽 끝에 둡니다. 위험 버튼은 주 버튼 왼쪽에 두고 사이를 `--space-3` 이상 띄웁니다.
- 승인은 실행 취소할 수 없지만 위험 모양이 아니라 주 버튼입니다. 결재자의 기본 동작이기 때문이고, 확인은 팝오버가 맡습니다. 위험 모양은 상대에게 불리한 일(반려, 결재 회수, 대결 해제)에만 씁니다.
- 눌림은 `--pressed` 덧칠(`box-shadow: inset 0 0 0 999px var(--pressed)`), 비활성은 `--opacity-disabled`. 팝오버가 열린 동안 그 팝오버를 연 버튼은 눌림 상태로 둡니다.

### 3.3 상태 표시와 태그

- **상태:** 7px 점 + 12~13px 글자(2.2절). 배지 면을 깔지 않습니다.
- **태그:** 한 가지 주의만 알릴 때 씁니다. `--fill-2` 면, `--text-2` 글자, 아이콘만 상태색(예: 사진에서 읽은 값 → 주황 사진 아이콘). 카드 하나에 태그는 하나까지.

### 3.4 목록(그룹 묶음)

- 행은 `--surface` 묶음(`--r-md`, `--shadow-1`) 안에 0.5px 구분선(왼쪽 16px 들여씀)으로 나눕니다. 묶음 머리는 `--fs-footnote` 600 `--text-2`, 오른쪽에 건수.
- **두 줄 행(결재 목록):** 아이콘(28px 둥근 사각, `--fill-2`) | 제목(14px 600) + 보조 줄(양식 · 기안자) | 오른쪽 금액(tnum, 600) + 시각. 셰브런은 붙이지 않습니다(상세가 옆에 열리므로).
- **값 행(상세·시트):** 라벨(`--text-2`, 84px) 왼쪽, 값 오른쪽 정렬. 금액은 행에 넣지 않고 맨 위로 뺍니다(3.6).
- 선택한 행은 `--sel` 면. 글자색은 바꾸지 않습니다.
- 표가 필요한 관리·평가 화면은 같은 규칙의 표를 씁니다: 머리 행 `--fs-caption` `--text-2`, 행 높이 44px, 숫자 열 오른쪽 정렬·tnum, 선택 행 `--sel`.

### 3.5 입력

- 입력칸·검색칸은 테두리 없이 `--fill-2` 면, `--r-sm`, `--control-h`. 초점은 `--focus-ring`.
- 라벨은 칸 위 `--fs-footnote` `--text-2`. 도움말은 칸 아래 `--fs-caption`(예: "반려할 때는 반려 사유를 적어 주세요"). 괄호 안 설명을 자리 표시 글에 넣지 않습니다.
- 날짜·시각 입력은 화면 표기와 같은 꼴(날짜 `2026. 11. 23.(월)`, 시 `오전 9시`)을 쓰는 자체 고르개로 둡니다. 화면 낭독기에는 `2026년 11월 23일 월요일`로 읽힙니다. 브라우저 기본 `datetime-local`은 언어에 따라 미국식으로 보여 쓰지 않습니다(heuristics H-D2).
- **세그먼트 컨트롤:** 탭 대신 씁니다. `--seg-track` 트랙(`--r-seg`, 안쪽 2px) 위 선택 칸 `--seg-thumb`(`--r-xs`) + `--shadow-1`. 건수는 tnum으로, 고르지 않은 칸은 `--text-2`, 고른 칸은 `--text`(어두움에서 `--text-2`는 선택 칸 위 대비가 모자람). `role="tablist"`, 화살표 키 이동.

### 3.6 실행 전 확인 시트(채팅)

에이전트가 쓰기 전에 확인을 받는 카드입니다(지금의 "실행 미리보기").

```
[제목 17px: 경비 정산 상신]                         [태그: 사진에서 읽은 값]
[금액 28px: 42,000원]  1인 10,500원 / 한도 15,000원  ✓ 식대 한도 안
[영수증 그림 + 크게 보기] | [값 행 묶음: 가맹점 · 사용일 · 용도 · 사업자번호]
👥 결재선  서도윤 팀장   결재 전 회수 가능
──────────────────────────────────────────────────────────
영수증과 맞는지 확인해 주세요. 오후 12:50까지   [취소] [경비 정산 상신]
```

- 시트는 `--surface`, `--r-lg`, `--shadow-pop`. 값은 양식 표시 이름 순서로, 원본(JSON)은 기본으로 숨기고 "자세히"로만 엽니다.
- 사진에서 읽은 값이면 영수증 그림을 값 옆에 둡니다(heuristics 우선순위 1).
- 실행 취소 불가인 일(결재 회수)은 시트 자체가 확인이라 팝오버를 더하지 않습니다. 실행 버튼을 위험 모양(`결재 회수`)으로, 결재선 줄 자리에 "실행하면 취소할 수 없습니다"를 둡니다.
- 결과: 실행하면 같은 자리에 **완료한 일** 행(`✓ 완료` + 요약 + 결재 문서 보기 + 실행 취소)으로 바뀝니다. 취소하면 "실행 안 함", 시간이 지나면 "진행 불가 · 확인 시간 지남".

### 3.7 결재 상세

```
경비 정산  EXP-0107  ● 결재 대기
팀 점심 식대                                   (22px)
(지현) 오지현  생산관리팀, 2026. 11. 20. 오후 12:44 상신
✓ 오지현 기안 ── ◷ 서도윤 팀장 결재 대기        (결재선, 가로 한 줄)
42,000원  1인 10,500원 / 한도 15,000원  ✓ 식대 한도 안
[값 행 묶음]                                  [영수증]
──────────────────────────────────────────────
[의견 ··················] [반려] [승인]
반려할 때는 반려 사유를 적어 주세요
```

- 결재선은 한국 결재 문서처럼 위에 둡니다. 대결 문서면 결재선 위에 "윤서진 팀장 대신 결재합니다. 대결은 2026. 11. 24. 오후 4:53까지"를 한 줄로.
- 승인을 누르면 승인 버튼 위로 꼬리 있는 **확인 팝오버**: 제목 "42,000원 경비 정산을 승인할까요?", 본문 "승인하면 결재가 끝나고, 승인은 취소할 수 없습니다.", 오른쪽 정렬 [취소] [승인]. Esc·바깥 클릭으로 닫힘, 초점은 팝오버 안 첫 버튼.
- 반려는 의견(반려 사유)이 비어 있으면 누를 수 없고, 이유를 칸 아래에 알립니다.
- 승인·반려 뒤에는 목록에서 다음 결재 대기 문서가 열립니다.

### 3.8 대화

- 내 말: 오른쪽 말풍선(`--accent-fill`, `--on-accent`, `--r-bubble`, 오른쪽 아래만 `--r-tag`).
- 에이전트 답: 면 없이 바탕에 바로. 위에 "재무 담당 AI · 사내 처리"(12px). 첫 문장에 결과(copy-guide 2.6).
- 근거 규정: 답 아래 "근거 규정 n건" 접기. 원문 대조가 안 된 인용은 그 인용 옆에 "원문 대조 안 됨"(`--warning` 아이콘).
- 입력창: 아래 고정, `--surface`, `--r-lg`, `--shadow-pop`. 왼쪽 아래 칩(사진 첨부, 자동 선택), 오른쪽 아래 둥근 보내기 버튼(`--r-full`, 30px). 보내기는 입력이 비면 `--fill` 면·`--text-2` 아이콘(비활성), 글이 있으면 `--accent-fill` 면·`--on-accent` 아이콘. 자리 표시 글은 입력 예시만("예: 다음 주 화요일 …").
- 대화 목록: 제목(일 이름) + 담당 AI + 상태 점 + 시각. 선택은 `--sel`.

### 3.9 팝오버·대화상자·토스트

| 종류 | 쓰는 때 | 모양 |
|---|---|---|
| 팝오버 | 버튼 하나에 딸린 확인(승인, 반려, 대결 해제) | 버튼 위 꼬리, `--r-lg`, `--popover-bg` + 흐림, `--z-popover`, 글 왼쪽 정렬, 버튼 오른쪽 |
| 시트(대화상자) | 화면을 막고 입력을 받는 일(새 대결 지정, 명령 팔레트) | 가운데 또는 오른쪽 서랍, 뒤에 `--scrim`, Esc로 닫힘, 초점 가둠 |
| 토스트 | 화면을 떠난 뒤 결과 알림(다른 사람이 먼저 결재함 등) | 오른쪽 아래, 4초, `role="status"`, 동작 하나(다시 불러오기) |

### 3.10 빈 상태·불러오는 중·오류

- **빈 상태:** 목록 자리에 한 문장 + 다음 행동 하나. "결재할 문서가 없습니다." / "아직 대화가 없습니다. 무엇을 할지 적어 보세요."(입력창으로 초점) 일러스트는 쓰지 않습니다.
- **불러오는 중:** 목록은 행 모양 뼈대(회색 막대 3줄, 깜빡임 없음), 300ms 안에 끝나면 보이지 않게 지연. 버튼은 글자 대신 작은 원형 표시 + 비활성.
- **오류:** 오류 문구는 제목만 보이고, 상세는 제목과 다를 때만 한 줄 더(copy-audit 2절의 제목·상세 중복). 무슨 일이 났는지 + 할 일(copy-guide 2.3). 다시 시도 버튼이 있으면 보조 버튼으로.

## 4. 접근성

- 글자 대비 4.5:1(큰 글자 3:1), 밝음·어두움 모두. `tokens.test.mjs`로 확인합니다.
- 상태는 색만으로 알리지 않습니다(점 + 글자).
- 모든 동작은 키보드로: 세그먼트·탭 화살표 키, 팝오버·시트 Esc와 초점 가둠, 명령 팔레트 Ctrl K.
- 초점 링은 지우지 않습니다(`--focus-ring`, 2px 불투명).
- 채팅 화면에도 `main`과 `h1`을 둡니다(a11y.md의 유일한 axe 위반).
- 움직임은 `prefers-reduced-motion`이면 끕니다.

## 7. 지금 web 토큰에서 옮기기

### 7.1 옮기는 순서

새 토큰은 간격 이름(`--space-*`)까지 지금 web 토큰과 이름이 겹치지 않거나, 겹치는 이름(`--bg`, `--surface`, `--text`, `--accent`, `--success` 등)은 같은 뜻입니다. 그래서 한 번에 바꾸지 않고 화면 단위로 옮길 수 있습니다.

1. 새 토큰을 `web/src/styles/tokens.css`에 **더합니다**. 지금 이름(`--sp-*`, `--fs-12` 등)은 남겨 둡니다. 겹치는 색 이름은 새 값으로 바뀌므로 이때 화면 색이 한 번에 바뀝니다.
2. 대비 시험을 새 토큰에 맞게 고칩니다(7.4).
3. 셸 → 채팅 → 결재 → 그 밖의 화면 순으로(#558 5단계) 새 이름으로 바꿉니다.
4. 지금 이름을 쓰는 곳이 없어지면 지웁니다.

### 7.2 이름 대응

| 지금 | 새 토큰 | 비고 |

### 7.4 대비 시험 옮기기

web의 `web/src/styles/contrast.test.ts`는 그대로 쓰면 새 토큰에서 깨집니다. 변수 이름 식이 숫자를 받지 않아(`--([a-z-]+)`) `--text-2`·`--surface-2`를 못 읽고, hex만 읽어 반투명 면(`--sel`, `--fill`) 위 대비를 보지 못하며, 시험 쌍의 `--text-muted`·`--on-fill`·`--local`이 없어집니다. `ux/design-system/tokens.test.mjs`의 방식(반투명 면을 아래 면과 섞어 계산, 어두움 블록만 읽기, 밝음 색 토큰이 어두움에 모두 있는지 확인)으로 바꾸고, 시험 쌍은 그 파일의 `PAIRS`를 옮깁니다.
