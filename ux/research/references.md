# 레퍼런스 후보

방향 "실제 회사가 쓸 만한 업무 프로그램이면서 현대적이고 트렌디한 웹 디자인"(사용자, 2026-11-22)에 맞는 공개 디자인 시스템과 제품 화면 후보입니다. 사용자가 이 중 두세 개를 고르면 #563(디자인 시스템 명세)이 그것을 기준으로 토큰·컴포넌트 규칙을 씁니다.

- 남의 제품 화면 스크린샷은 저장소에 넣지 않습니다. 링크만 적고, 이미지가 필요하면 관리 폴더에 둡니다.
- "가져올 것"은 모양을 베끼는 것이 아니라 **규칙과 패턴**입니다. 코드·아이콘·서체를 가져올 때는 라이선스를 따로 확인합니다.
- 링크는 2026-11-22에 열리는 것을 확인했습니다.

## 2. 고르는 데 도움이 될 묶음

| 묶음 | 후보 | 이 묶음을 고르면 |
|---|---|---|
| 운영 도구형(A)에 무게 | R1 Linear + R2 Geist + R5 Carbon | 표·목록이 빽빽하고 차분한 회색조. 승인함·관리 콘솔이 강해짐 |
| 대화 비서형(B)에 무게 | R6 Fluent 2 + R10 Ramp + R2 Geist | 채팅과 오른쪽 패널(미리보기·결재)이 중심. 직원 과업이 강해짐 |
| 섞음(추천) | R1 Linear(셸) + R2 Geist(토큰) + R10 Ramp(경비·결재 흐름) | 셸·탐색은 Linear처럼, 색·간격은 Geist처럼, 미리보기 카드·결재 상세는 Ramp처럼 |

추천 이유: 휴리스틱 평가에서 가장 많은 문제는 탐색(N6)과 값 표시(N2)였고, 가장 큰 문제는 경비 미리보기(H-P1)였습니다. 셸은 R1, 값 표시는 R10이 직접 답을 줍니다. 토큰은 R2가 밝음·어두움을 같은 이름으로 다뤄 지금 `tokens.css` 구조와 맞습니다.
