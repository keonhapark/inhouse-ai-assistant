# 휴리스틱 평가(닐슨 10원칙)

지금 화면(재설계 전)을 닐슨 10원칙으로 본 결과입니다. 평가자는 사람이 아니라 에이전트 둘입니다.

- **평가 1(이 문서 1~2절):** 과업 스크립트를 만든 세션이 화면과 코드를 보고 매겼습니다.
- **평가 2(3절):** 결론을 모르는 서브에이전트가 같은 화면만 보고 따로 매겼습니다. 원문은 [heuristics-independent.md](heuristics-independent.md)입니다.

근거 화면은 web 모의 데이터 모드 캡처(`a11y/baseline/shots/`, `walkthrough/baseline/shots/`)와 실제 스택 캡처(`web/docs/images/real-*.png`)입니다. 실제 스택에서만 보이는 문제는 "실제"로 표시했습니다.

심각도:

- **사용을 막음:** 과업을 못 끝내거나, 잘못된 결재·실행으로 이어질 수 있음
- **헷갈림:** 끝내기는 하지만 망설이거나 잘못 읽음
- **다듬기:** 보기 좋지 않거나 일관성이 없음

원칙: N1 시스템 상태 보이기, N2 실제 세계와 맞추기, N3 사용자 통제와 자유, N4 일관성과 표준, N5 오류 예방, N6 기억보다 알아보기, N7 유연성과 효율, N8 미니멀한 디자인, N9 오류 인식·진단·복구, N10 도움말

### 3.1 둘 다 찾은 것(겹침)

경비 미리보기의 날것 값(둘 다 **사용을 막음**), 회수 미리보기의 영문 상태값, 채팅의 도구 이름·라우팅 문장, 첫 메시지로 고정되는 대화 머리, 같은 대화 제목, 결재 탭·메뉴의 건수 없음, 늘 펼쳐진 대결 패널, 맡긴/맡은 위임이 섞인 목록, 미국식 날짜 입력과 날짜 형식 혼재, 반려 의견 선택, 조직도 사람 찾기 없음, 에이전트 화면의 코드 이름, 감사 로그의 `emp-`·`hr`·작업 코드, 외부 전송 기록에 직원·대화가 없음, 평가 시나리오 ID와 긴 페이지. 평가 1의 문제 40건 중 32건이 평가 2에도 있습니다(일부만 겹친 것 포함).
