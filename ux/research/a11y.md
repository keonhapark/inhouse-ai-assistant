# 접근성 자동 점검(axe-core)

지금 화면(재설계 전)의 화면 14개를 밝음·어두움 두 테마로 axe-core에 돌린 결과입니다. 스크립트는 `ux/a11y/run.mjs`, 원자료는 [a11y/baseline/results.json](a11y/baseline/results.json), 화면별 표는 [a11y/baseline/results.md](a11y/baseline/results.md)입니다.

- 도구: axe-core 4.14(`@axe-core/playwright`), 규칙 묶음 WCAG 2.0·2.1·2.2 A/AA와 best-practice
- 환경: web 모의 데이터 모드(msw), Chromium headless, 1280×800, `prefers-color-scheme` 밝음·어두움
- 화면 상태: 빈 화면만이 아니라 답·근거 펼침·실행한 일 카드, 실행 미리보기, 문서 상세, 위임 미리보기처럼 과업 중간 상태를 만든 뒤 점검했습니다.

## 1. 결과

| 화면 | 위반 규칙(밝음/어두움) | 위반 요소 | 내용 |
|---|---|---|---|
| 로그인, 로그인 오류 | 0 / 0 | 0 | |
| 채팅 빈 화면 | 2 / 2 | 2 | `landmark-one-main`, `page-has-heading-one` |
| 채팅 답·근거·실행한 일 | 2 / 2 | 2 | 같음 |
| 채팅 실행 미리보기 | 2 / 2 | 2 | 같음 |
| 승인함(내 차례, 문서 상세, 위임 미리보기) | 0 / 0 | 0 | |
| 조직도, 에이전트 | 0 / 0 | 0 | |

| 평가 리포트 | 0 / 0 | 0 | |
| **합계(28회 점검)** | **12건** | **12** | 모두 moderate, critical·serious 0 |

- 위반은 채팅 화면 한 곳의 구조 문제뿐입니다. 채팅 화면에 `main` 랜드마크와 `h1`이 없습니다(대화 목록은 `nav`, 대화는 `section`). 스크린리더 사용자가 "본문으로 건너뛰기"나 제목 이동으로 대화에 바로 가지 못합니다.
- 색 대비 위반은 0건입니다. web에 이미 토큰 대비 시험(`web/src/styles/contrast.test.ts`)이 있습니다.

## 2. axe가 판정하지 못한 것

| 규칙 | 요소 수(28회 합) | 뜻 |
|---|---|---|
| `color-contrast` | 152 | 배경이 겹치거나 반투명이라 자동으로 대비를 계산하지 못한 요소입니다. 대부분 배지(테두리 + 옅은 배경)와 카드 위 보조 글입니다 |
| `bypass` | 6 | 본문 건너뛰기 수단이 있는지 확정하지 못했습니다 |

- 152개는 위반이 아니라 "사람이 봐야 함"입니다. 재설계에서 배지·보조 글 색을 정할 때 이 요소들을 직접 계산합니다(#563).

## 3. 자동 점검이 보지 못하는 것

axe는 WCAG 문제의 일부만 잡습니다. 아래는 이번에 자동으로 보지 않았고, 화면과 코드에서 눈으로 본 것입니다. 재설계 뒤 키보드 시험을 스크립트로 더합니다(#564).

| 항목 | 지금 상태 | 근거 |
|---|---|---|
| 키보드로 모든 동작 | 탭·버튼이 기본 요소라 키보드로 됩니다. 승인함 탭은 화살표 키를 지원합니다 | `web/src/inbox/InboxPage.tsx` |
| 초점 표시 | 입력창은 초점 테두리가 보입니다. 머리글 링크의 초점 모양은 확인하지 않았습니다 | `dark-채팅-답-근거-실행한-일.jpg` |
| 상태 알림 | 처리 결과·오류가 `role="status"`·`role="alert"`로 읽힙니다 | `web/src/inbox/InboxPage.tsx`, `web/src/chat/ChatPage.tsx` |
| 날짜 입력 | `datetime-local`이 브라우저 언어를 따라 미국식으로 보일 수 있습니다(접근성보다 지역화 문제) | `light-승인함-위임-미리보기.jpg` |
| 좁은 폭·확대 200% | 보지 않았습니다 | |

## 4. 해석

자동 점검 기준으로 지금 화면은 이미 깨끗한 편입니다. 접근성은 재설계의 출발점이 아니라 **지켜야 할 기준선**입니다. 재설계 뒤 같은 스크립트로 위반 0건(채팅의 `main`·`h1` 포함)을 목표로 하고, `color-contrast` 판정 불가 요소가 늘지 않게 봅니다.
