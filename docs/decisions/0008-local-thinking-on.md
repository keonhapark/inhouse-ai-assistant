# 0008. 로컬 모델의 생각 단계를 다시 켭니다

- 날짜: 2026-11-22
- 정한 사람: 사용자

## 결정

로컬 모델(Qwen3.5-9B) 호출에서 생각 단계를 끄던 설정(#424 agent 계획 호출, #427 gateway가 로컬로 돌린 호출)을 되돌려 모델 기본값(생각 켬)으로 둡니다. 대신 agent·gateway의 로컬 호출 시간 초과를 60초에서 120초로 늘립니다.

## 이유

- #423 측정(코랩 T4, 첫 계획 호출 85개): 기대 도구 호출이 생각 끔 28/46, low 43/46, 켬 44/46입니다. 끄면 도구를 부르지 않고 "하겠습니다"로 말만 끝나는 경우가 많습니다.
- 정상 셋 v2(#506)에서 full의 실패 대부분이 로컬 경로에서 업무 도구를 부르지 않은 것이고, 탐색 비교(#513)의 열세도 같은 원인입니다.
- 지연은 늘어납니다(첫 계획 호출 p50 3.1초 → 10.3초, gateway 로컬 돌림 p50 2.96초 → 8.19초, 최대 79.9초). 업무를 잘못 처리하는 손해가 기다리는 손해보다 크다고 봅니다.

## 버린 대안

- 생각 끔 유지: 빠르지만 도구 호출을 놓칩니다.
- low: 켬과 정확도·지연이 거의 같아 얻는 것이 없습니다.

## 영향

- 이 결정 전에 생각 끔으로 잰 결과(확인 셋 1회 #447, 정상 셋 v2 #506, 모델 교체 회귀 #442·#525)는 그 설정의 결과로 남기고, 보고서에 설정을 밝힙니다. 정상 셋 v2는 켠 설정으로 다시 잽니다.
- 도구 호출 확인 묶음(#454)의 로컬 변형은 원래 생각 켬으로 쟀으므로 다시 재지 않습니다.
