# 0007. 2단계 확인 셋·도구 호출 확인 묶음은 한 번 돌린 결과로 냅니다

- 날짜: 2026-11-22
- 정한 사람: 사용자

## 결정

- 확인 셋 confirm-v1은 여섯 조건 × 1회(450회차, pass^1) 결과(#447)로 2단계 주 결과를 냅니다. 프로토콜 8절의 나머지 2회는 지금 돌리지 않고 뒤로 미룹니다(#452).
- 도구 호출 확인 묶음 toolcall-v1은 세 변형(S0 local, fewShot local, external)을 1회씩 돌려 1회차끼리 비교합니다. S0 local은 이미 돌던 3회를 끝까지 돌려 부록에 pass^3로 붙입니다.
- 정상 셋 v2와 2단계 에이전트 묶음도 조건마다 1회 돌립니다.

## 이유

- 로컬 모델 측정은 이 기기의 GPU 한 장(RTX 4070 SUPER 12GB)을 차례로 씁니다. confirm-v1 1회에 약 3시간 15분이 걸렸고, 3회면 같은 시간이 두 번 더 듭니다. 그동안 정상 셋 v2, 모델 교체 회귀, 모듈 측정이 모두 기다립니다.
- confirm-v1 1회 결과에서 이 프로젝트와 기성 도구 기본의 사고율 차이 구간(-18.6~-1.1%p)이 0을 포함하지 않습니다. 반복은 결과를 단단하게 하지만 주장의 방향을 바꾸는 데 필요하지는 않습니다.
- 반복을 줄이는 결정은 1회 결과를 본 뒤에 했습니다. 결과가 기대와 달라서가 아니라 대기열 때문이라는 점을 남깁니다.

## 버린 대안

- 프로토콜 그대로 3회: confirm-v1만 약 6시간 30분이 더 들고, toolcall-v1도 1,080회차가 됩니다.
- 나머지 반복을 다른 기기(코랩 T4)에서 돌리기: 1회차와 기기·양자화 실행 환경이 달라 반복끼리 섞을 수 없습니다.

## 나중에 할 일

- confirm-v1 2·3회차(#452): 1회차와 같은 스택 b822881·하네스·팩 단계로 고정하고(#449·#451), 끝나면 pass^3로 보고서를 다시 냅니다.
