# 0002. 1단계 평가는 정상 셋을 세 조건으로 한 번 돌립니다

- 날짜: 2026-11-20
- 정한 사람: 사용자

## 결정

1단계 보고서는 정상 셋 80개를 `full`·`no_guard`·`write_blocked` 세 조건에서 한 번씩(240회차) 돌린 결과로 냅니다. 프로토콜 8절의 3회 반복에서 바꾼 것이라 보고서에 pass^1로 표시합니다. 나머지 2회는 2단계에서 돌려 pass^3를 냅니다(#128).

## 이유

- 시험 실행에서 회차당 약 75초(로컬 Qwen3.5-9B, M1 Pro)였습니다. 3회 반복이면 720회차로 이 기기에서 약 15시간입니다.
- 한 번 돌린 결과로 고칠 것을 먼저 찾고, 반복은 그 뒤에 해도 실행 비용을 아낄 수 있습니다.
- 개발 셋은 프로토콜 6절대로 주 결과에 쓰지 않으므로 반복하지 않습니다. 전건 승인·기성 도구 기본 조건과의 비교는 확인 셋에서 합니다.

## 버린 대안

- 프로토콜 그대로 3회(720회차): 이 기기에서 하루 가까이 걸립니다.
- 개발 셋까지 다섯 조건 × 3회(2,100회차): 결과에 쓰지 않는 셋을 반복합니다.
