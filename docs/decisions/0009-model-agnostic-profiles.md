# 0009. 모델은 설정으로 고르고, 모델마다 다른 설정은 모델 프로필에 둡니다

- 날짜: 2026-11-23
- 정한 사람: 사용자

## 결정

이 프로젝트가 만드는 것은 특정 모델이 아니라 모델과 무관하게 동작하는 하네스(gateway·agent·rag·eval)입니다. 모델은 계속 바뀌므로 다음을 원칙으로 둡니다.

1. 호출하는 쪽은 별칭(`local`, `external` 등)만 쓰고, 어떤 모델·API를 쓸지는 설정(LiteLLM 별칭 표)에서 고릅니다. 로컬 모델이든 외부 API든 같은 방식으로 고릅니다.
2. 모델마다 다른 실행 설정(생각 단계 켬·끔, 시간 제한, 구조화 출력 지원, 이미지 입력 여부)은 코드나 전역 환경 변수가 아니라 별칭별 **모델 프로필**에 둡니다. 0008의 "로컬 생각 켬"은 Qwen3.5-9B 프로필의 값입니다.
3. 모델을 바꿀지는 회귀 시험(정상 셋·도구 호출 확인 묶음·확인 셋)으로 판단하고, 보고서에 모델·프로필을 밝힙니다. 더 나은 결과가 나와도 이미 쓰는 모델을 지우지 않고 별칭을 추가해 나란히 둡니다.

## 이유

- 같은 개발 묶음에서 Qwen3.5-9B는 생각을 켜야 도구를 부르고(끔 24/46, 켬 43/46), Gemma 4 12B는 생각을 끄는 쪽이 낫습니다(끔 43/46, 켬 38/46, #586). 생각 설정을 전역으로 두면 모델을 바꿀 때마다 코드와 설정을 함께 고쳐야 합니다.
- Sonnet·K-EXAONE 교체 회귀(#442·#525)처럼 모델 교체를 시험으로 확인하는 틀은 이미 있습니다. 프로필을 두면 교체가 설정 한 줄과 회귀 시험 한 번이 됩니다.

## 영향

- gateway·agent·rag의 생각 단계·시간 제한 설정을 별칭 프로필에서 읽게 바꿉니다(#595).
- 운영 화면에서 지금 별칭이 어떤 모델·프로필인지 보이게 합니다(#595).
